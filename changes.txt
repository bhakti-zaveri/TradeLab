[Viva] System Refactor - Auth, DB, State

Technical Summary:
- Executed a complete full-stack migration from temporary in-memory arrays to a persistent SQLite-backed database using Drizzle ORM.
- Stripped all external proprietary branding (e.g., Replit plugins and dependencies) to fully white-label the application.
- Configured a local `.env` environment to correctly anchor `local.db` path resolution across workspaces.
- Created `seed.ts` script and populated the database with standard testing credentials (demo@tradelab.app).
- Integrated `requireAuth` middleware to intercept API requests and inject the seeded testing user profile.
- Restructured `tradelab.ts` API endpoints (`/dashboard`, `/portfolio`, `/orders`, `/trades`, `/journal`, `/analytics`) to operate dynamically against the `users`, `accounts`, `positions`, `orders`, and `trades` tables.
- Refactored the Replay Terminal order ticket to validate risk before execution. The frontend and backend now enforce a mandatory stop-loss for every trade and automatically reject orders that exceed a 2% equity risk threshold.
- Hooked up the 'Behaviour Lab' analytics dashboard to derive real equity curves and drawdown calculations directly from the `trades` ledger.
- Extended the SQLite schema to capture the user's `confidence` rating during Post-Trade journaling workflow.

The core infrastructure is now robust, stateful, and ready for advanced market data integrations.

- Built a new beginner-friendly 'Academy' module (available under 'Learn' in the sidebar) to teach fundamental market mechanics. This feature was built specifically to lower the barrier to entry for retail beginners and to improve user retention by reducing platform confusion.
- Removed 2% risk execution blocker. Orders with sufficient capital will now execute freely.
- Fixed the journaling flow: removed journal prompts from error toasts and introduced a dedicated post-trade popup modal.
- Enforced complete Indian market localization: replaced $ with ₹ across the platform, implemented INR format (en-IN), and updated the simulated instruments to exclusively feature NIFTY 50 Indian tickers.
